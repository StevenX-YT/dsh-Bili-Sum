# 图文转录渲染规范（transcript-pretty）

适用：用户要「完整文稿 + 必要处配图」的场景（两种 type 通用）。
产出：单个 HTML 文件，放在 output/<bv>_pN/ 目录（与 frames/ 同级）。

## 结构

1. 元信息头（同 lecture-notes / video-digest 规范的元信息块）
2. 转录正文：按 `bundle.keyMoments` 切章节，每章节一个 `<details open>` 块
3. **配图规则**：每个 keyMoment 若 `nearestFrame` 存在且 deltaSec ≤ 30，插入该帧（`frames/kf_xxx.png`）+图注（时间戳 + 一句话说明画面）；无帧处不硬配
4. 时间戳行格式：`<span class="ts">[mm:ss]</span> 文本`，作为可检索锚点
5. 章节导航：顶部目录锚点列表（章节名 + 时间段）

## 规则

- 文稿渲染前**静默校正**：术语/人名按上下文直接替换为正确形式（如 微信→唯一、玄珍树→悬针竖）——不保留误写、不加括号标注，保证显示结果完全正确；确实无法判断的词保留原样
- 图注说明画面内容（板书写了什么 / 演示了什么），不是复述语音
- 长文稿（>800 段）拆分为多个 HTML（每 300 段一个），文件名带区间
