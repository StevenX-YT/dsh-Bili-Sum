# 视频速览渲染规范（video-digest）

适用：`analyze type=general` 产出的 bundle + transcript + frames。
目标：**三层信息密度**——30 秒（摘要）→ 2 分钟（亮点/Q&A/术语）→ 5 分钟（章节叙述），读者按时间预算取用。
质量标杆：用户提供的另一 AI 导出文件（见 reference-bar.md），并修复其缺陷。

## 固定结构

1. **头部**：`AI 摘要：<标题>` + **元信息块**（BV/链接/UP主/时长/发布日期/播放·点赞·弹幕/内容属性）——缺失字段显式写「未提供」，不得省略（修复标杆的不可溯源缺陷）
2. **摘要**（2 段，≤150 字/段）：事件起因 + 作者核心论点 + 结尾断言，段内内嵌 [MM:SS]
3. **亮点**（≥10 条）：`emoji + 短句 + 原话引用 + [MM:SS]`，按时间序；原话从转录逐字摘
4. **标签**：5–8 个 hashtag
5. **思考 Q&A**（≥3 组）：问题行**也带 [MM:SS]**（修复标杆缺陷）；回答区分「视频中提到」与「延伸思考」
6. **术语解释**：术语 + 一句话定义 + [MM:SS]
7. **章节总结**：`MM:MM–MM:MM` **区间**格式 + 80–150 字正文，**覆盖全片**；广告/推广位单独标注（如「04:26 京东剃须刀植入」）
8. **观点归因**：每条论点标「作者认为 / 视频中提到 / 事实是」，禁止无主语断言（修复标杆的信誉底线问题）
9. **配图**：关键帧缩略图网格 ≤6 张（选信息量大者），HTML 中相对路径引用 frames/
10. **弹幕精选**（可选，≥3 条才放）：只选四类——①梗与刷屏名场面（标注"刷屏"）②不同观点与反驳③实用指引（"看XX更清楚/跳到XX"）④高赞神评；带 [MM:SS]；打卡、水弹幕、无信息量互动一律不放

## 渲染规则

- 时间戳统一 [MM:SS]；章节块用区间 [MM:MM–MM:MM]
- **页面 CSS 必须自带 `.ts` 蓝底徽章样式**（如 `.ts{display:inline-block;background:#0054a6;color:#fff;border-radius:4px;padding:0 6px;font-size:12px}`）——tsGal 运行时把 .ts 转成链接后强制白字（`a.ts-jump{color:#fff}`），页面不给蓝底则时间戳白字贴白底=隐形（2026-10-03 实战踩坑）
- 亮点条目固定格式，不自由发挥；引用逐字，不改写
- **不输出勘误表**：引用与术语在渲染前静默校正，保证显示结果直接正确
- 弹幕疑问、无信息量互动不进正文；只有「弹幕精选」的四类可放
- 语言紧凑、书面；敏感话题保持转述中立，不加站队评论
- **时间戳画廊 + B站小窗播放（tsGal v3.6）**：所有 `.ts` 蓝色徽章可点击——**左键在页内右下角悬浮小窗直接播放对应秒数**
  （B站官方外链播放器；可拖动/缩放（防粘连）/ESC关闭；v3.6 起页面内字幕系统已移除，看字幕走右键B站站内播放），
  右键仍可在B站新标签页空降；亮点/摘要处还自动挂折叠画廊（展开+左右滚动+逐帧转录标注），
  渲染完成后执行 `& scripts\inject-gallery.ps1 -HtmlPath <digest.html>`；规范见 lecture-notes.md 的 tsGal v3.6 一节
