# 课程笔记渲染规范（lecture-notes）

适用：`analyze type=lecture` 产出的 `bundle.json` + `transcript.txt` + `frames/`。
产出：HTML 笔记（图内嵌，与 frames/ 同目录）+ 对话内 markdown 精华版。

## HTML 固定结构

1. **元信息头**：标题 / UP主 / BV 可点链接 / 分P与时长 / 播放·点赞·弹幕数 / 生成时间 / 转录模型·线程·耗时
2. **TL;DR**（≤120 字）：这节课讲什么 + 一句话掌握目标
3. **知识框架表**：编号 | 名称 | 定理/性质内容 | 讲解时间段 | 对应板书缩略图
4. **分段精讲**（3–6 块）：每块 = `[mm:ss–mm:ss]` 小标题 + 要点列表（每条带 [mm:ss]）+ 板书配图（取 `keyMoments[].nearestFrame` 或 `frames[]` 中最近的一张，用相对路径 `frames/kf_xxx.png`）+ 例子/反例/类比
5. **易错易混难点与解答**（agent 自著，3–6 条）：每条 = 难点/易混点 + 为什么容易错 + 正确理解与解法 + 讲解时间戳锚点（`.ts` 徽章，tsGal 画廊自动挂上）。素材来源：①转录内容分析；②`danmakuSignals` 的疑问信号仅用于**定位**难点位置（不引用弹幕原文）；③必要时 `web_search` 查证教材/讲义——陌生领域先查再写
6. **复习清单**：5–8 条可勾选掌握点（覆盖知识框架表每一行）
7. **附录**：`<details>` 折叠完整转录（带时间戳行），summary 注明「原始转录仅供对照，正文已校正」

## 渲染规则

- 所有论断带 [mm:ss]；**定理/公式/符号以板书画面为准**，语音负责讲解逻辑与例子
- **页面 CSS 必须自带 `.ts` 蓝底徽章样式**（如 `.ts{display:inline-block;background:#0054a6;color:#fff;border-radius:4px;padding:0 6px;font-size:12px}`）——tsGal 运行时把 .ts 转成链接后强制白字（`a.ts-jump{color:#fff}`），页面不给蓝底则时间戳白字贴白底=隐形
- 保留老师的关键类比与原话（加引号），这是课程笔记的记忆锚点
- **显示正确性是硬要求**：正文/图表/图注中的术语、公式、人名直接显示正确形式（赵孟頫、悬针竖、函数极限……），渲染前静默校正——**不输出勘误表**，不暴露 ASR 误写
- **弹幕不进课程笔记正文**：不展示弹幕疑问、打卡、闲聊；弹幕只作为内部定位难点的线索（疑问高发处 = 大概率难点）
- 对话内精华版：TL;DR + 知识框架表 + 难点解答 + 复习清单，不贴图（HTML 已有）

## 时间戳折叠画廊 + B站小窗播放（tsGal v3.6，必装功能）

每个蓝色 `.ts` 时间戳徽章是**可点击元素**：**左键点击 → 页内右下角悬浮小窗播放对应秒数**；
右键「在新标签页打开」/ 复制链接仍走标准 B站空降页。单点徽章跳该秒；区间徽章跳区间起点；画廊每帧时间戳同样可点。

### 视频源双通道（核心，实测取证后的架构）

**实测结论**：B站 CDN 对视频直链**强制校验 Referer**——带B站 Referer：200+可 seek；
无 Referer（file:// 页面的 `<video>` 只能发 null）：**403**。这就是 file:// 直开时空降失效、
延续上次播放的根因：原生播放器加载不了直链，实际落到B站播放器 iframe，而 iframe 登录态下会按观看历史自动续播。

- **A. 本地服务器模式（推荐，空降/暂停全完美）**：
  `node scripts\serve-notes.mjs`（默认端口 8930，占用自动顺延）→ 打开 `http://127.0.0.1:8930/`（有笔记列表落地页）
  → 小窗播放走 `/proxy` 代理（自动补B站 Referer、透传 Range、中断自愈）→ 原生 `<video>` 完整支持
  seek/点击暂停。视频仍由B站 CDN **在线流式传输，不下载到本地**。
- **B. file:// 直开模式**：自动回退B站播放器 iframe（sandbox 防跳转；登录态下 t= 空降可能被观看历史续播干扰——B站播放器行为）；
  页面会一次性提示用本地服务器解锁完整能力。

### 字幕系统（v3.6 已移除）

v3.6 起页面内字幕系统（中间行高亮/⚙设置面板/timeupdate 联动/±5s 微调）已整体移除——
相关代码与规范拆出留档于 `archive-subtitles/`（含 v3.5 完整回退点），需要时可整体回退或精准重装。
字幕替代路径：小窗右键「在B站新标签页打开」用B站播放器（B站字幕在站内可用）；笔记正文本身以图文+折叠转录承载内容。

### 小窗操作

右下固定、标题栏拖动移动、右下角拖拽调宽（pointer capture 防粘连，宽度记忆）、
双击标题栏复位、ESC/关闭隐藏（隐藏即停播）、标题栏「B站全页」跳标准空降页；
拖角旁不放跳转链接，避免误触。
- 实现：`templates/gallery-runtime.js`（v3.6，零依赖）+ `scripts/fetch-stream.mjs`（注入时在线取直链）+ `scripts/serve-notes.mjs`（本地服务器/代理）；
  渲染完成后执行注入（幂等，旧版自动就地升级）：`& scripts\inject-gallery.ps1 -HtmlPath <笔记.html>`
- 注入数据：bundle.json 的 frames + video（title/part）+ **stream（直链 URL/画质/有效期）**内联为 `window.__TSGAL__`，
  转录取自页内 `<pre id="transcript">`——成品 HTML **file:// 直接可开**；播放需联网；
  **直链有效期过后（通常数天）自动回退B站播放器**，如需恢复原生直链重新执行一次注入即可。
- 选帧规则：区间徽章取 `[start-15s, end+15s]` 内的帧（最多 6 张，超出按序均匀取样）；单点徽章取 ±35s；
  窗口内无帧则就近取 3 张。画面时间以 bundle.json 的 timeSec 为准。
- 挂载规则：`li / .tip / .err` 的徽章 → 画廊插在元素末尾；`h3` 徽章 → 画廊紧跟标题后；
  表格 `td` 内的徽章只做小窗链接化（不挂画廊，保持表格紧凑）。
- 需要更精细的「看点注释」（如动作分解步骤）时，改为手写静态 `<details class="tsGal">`，
  figcaption 里加 `<b>看点：</b>` 行——runtime 检测到页面已有画廊会跳过重复构建。
